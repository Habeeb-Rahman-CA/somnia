TREATISE I • DETERMINISTIC PSEUDORANDOMNESS

The Mulberry32 State Engine

Standard JavaScript Math.random() lacks seed parameterization; its state cannot be serialized or replicated. In fine art procedural generation, determinism is essential: a composition must reproduce its exact line trajectories regardless of when or where it is evaluated.

State Evolution Equation: 
let t = (state += 0x6D2B79F5);
t = Math.imul(t ^ (t >>> 15), t | 1);
t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
return ((t ^ (t >>> 14)) >>> 0) / 4294967296;

Mathematical Properties

  • Full 32-bit state space: Period of 232 (~4.29 billion values) before cycling.
  • Golden Ratio constant: 0x6D2B79F5 is derived from 232 / ϕ, ensuring maximal dispersion of initial state bits.
  • Bit Avalanche: Bitwise XOR shifts and integer multiplication ensure that altering a single seed bit cascades unpredictably through subsequent pseudorandom values.
  • Box-Muller Normal Transform: Enables sampling normal Gaussian distributions for particle lifespan: Z = √(-2 ln U₁) · cos(2π U₂).
TREATISE II • CONTINUOUS GRADIENT FIELDS

2D Simplex Geometry

Classic Perlin noise partitions coordinate space into rectilinear grids, imparting directional square bias and visual alignment seams. 2D Simplex noise tessellates space into an isotropic grid of equilateral triangles (simplices), producing continuous rotational symmetry.

Simplicial Coordinate Transformation: 
// Skew factor for 2D: F = (√3 - 1) / 2 ≈ 0.366025
const s = (x + y) * 0.36602540378;
const i = Math.floor(x + s), j = Math.floor(y + s);

// Unskew factor for 2D: G = (3 - √3) / 6 ≈ 0.211325
const t = (i + j) * 0.21132486540;
const x0 = x - (i - t), y0 = y - (j - t);

Continuity & Scale

  • Radial Hermite Spline: Each vertex contributes: (0.5 - r²)⁴ · (grad · dist). Because both magnitude and first derivative vanish smoothly at r = √0.5, the field exhibits seamless C¹ continuity.
  • Fractal Brownian Motion (fBM): Superimposes multiple harmonic octaves: fBM(x, y) = ∑ (noise(x · 2ⁱ, y · 2ⁱ) · 0.5ⁱ).
TREATISE III • VECTOR DYNAMICS

Incompressible Curl Noise

A vector field assigns a velocity vector V(x, y) = (vx, vy) to every spatial coordinate. To avoid particle collapse into empty sinks, Somnia derives an incompressible curl component.

Trigonometric Projection & Curl Equations: 
θ = noise(x · scale, y · scale) · 2π + directionBias
vx = cos(θ) · flowStrength
vy = sin(θ) · flowStrength

TREATISE IV • SIMULATION KINEMATICS

Filament Trajectories & Dissolution

Rather than disconnected points, Somnia records the temporal history of each tracer as connected line segments rendered in dilute monochrome inks.

Integration & Segment Drawing: 
p.prevX = p.x;
p.prevY = p.y;
p.x += p.vx;
p.y += p.vy;

ctx.beginPath();
ctx.moveTo(p.prevX, p.prevY);
ctx.lineTo(p.x, p.y);
ctx.stroke();

Decay & Dissolution

  • Atmospheric Decay: On each frame, an ultra-faint dark veil (alpha 0.02 – 0.06) washes across the canvas, gently dissolving older paths into memory.
  • Toroidal Wrapping: Screen boundaries wrap particles seamlessly, resetting prevX, prevY to prevent cross-canvas visual lines.

TREATISE VI • PRECISION & OPTIMIZATION

Optimization & Reproducibility

Sustaining 60 frames per second with thousands of active filaments while guaranteeing bit-for-bit static exports:

  • Zero Allocations in RAF: Particle arrays are pre-allocated at initialization and recycled in place. No Garbage Collection stutters occur.
  • High-DPI Retina Compensation: Canvas backing store is scaled by window.devicePixelRatio, rendering hairline paths with etching-press sharpness.
  • Deterministic Offscreen Rendering: Exports run 320 discrete ticks (dt = 1/60s) on an offscreen canvas, ensuring pixel-perfect reproduction across all displays.
