Procedural Determinism

Deterministic Pseudorandomness (Mulberry32)

In standard JavaScript, Math.random() is non-deterministic and cannot be initialized with a custom seed. As a result, an artwork generated with Math.random() is completely lost the moment the tab is refreshed, and identical visual exports are impossible.

Mulberry32 State Evolution Algorithm: 
let t = (state += 0x6D2B79F5);
t = Math.imul(t ^ (t >>> 15), t | 1);
t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
return ((t ^ (t >>> 14)) >>> 0) / 4294967296;

Why Mulberry32?

  • Full 32-bit state space: Period of 232 (~4.29 billion values) before repeating.
  • Golden Ratio increment: 0x6D2B79F5 is derived from 232 / ϕ, ensuring maximal dispersion of initial state bits.
  • Avalanche effect: Bitwise XOR shifts and integer multiplication (Math.imul) ensure that changing a single seed bit dramatically alters all subsequent pseudorandom values.
  • Box-Muller Transform: Enables sampling normal Gaussian distributions for particle lifespan and spatial jitter: Z = √(-2 ln U₁) · cos(2π U₂).
Continuity & Gradient Fields

2D Simplex Noise Field

Traditional Perlin noise subdivides space into a square grid. This introduces noticeable directional bias and grid-aligned visual artifacts. Simplex noise replaces squares with a tessellation of equilateral triangles (simplices), producing isotropic continuity with zero grid bias.

Simplicial Coordinate Transformation: 
// Skew factor for 2D: F = (√3 - 1) / 2 ≈ 0.366025
const s = (x + y) * 0.36602540378;
const i = Math.floor(x + s), j = Math.floor(y + s);

// Unskew factor for 2D: G = (3 - √3) / 6 ≈ 0.211325
const t = (i + j) * 0.21132486540;
const x0 = x - (i - t), y0 = y - (j - t);

Mathematical Properties

  • Radial Hermite Spline: Each vertex contributes based on distance: (0.5 - r²)⁴ · (grad · dist). Because both value and derivative drop smoothly to zero at r = √0.5, the field has seamless C¹ continuity without visual seams.
  • Fractal Brownian Motion (fBM): Superimposes multiple harmonic octaves: fBM(x, y) = ∑ (noise(x · 2ⁱ, y · 2ⁱ) · 0.5ⁱ), introducing subtle micro-eddies alongside grand atmospheric swells.
  • Influence of Scale: Low scale (< 0.002) creates sweeping planetary laminar ribbons; higher scale (> 0.008) yields tight labyrinthine whorls.
Vector Dynamics

Flow Fields and Curl Noise

A flow field converts continuous 2D scalar noise into a vector field V(x, y) = (vx, vy). Each point in space defines an angle θ:

Trigonometric Projection & Curl Formulation: 
θ = noise(x · scale, y · scale) · 2π + directionBias
vx = cos(θ) · flowStrength
vy = sin(θ) · flowStrength

// Divergence-Free Incompressible Curl:
// V_curl = (∂ψ/∂y, -∂ψ/∂x)  where  ∇ · V_curl = 0

Preventing Particle Clumping

In ordinary noise fields, particle trajectories tend to converge into sink lines, leaving vast expanses of the canvas empty. Somnia evaluates the numerical curl of the scalar potential field via central differences: ∂n/∂x ≈ [n(x+ε) - n(x-ε)] / 2ε. Because the divergence of the curl is identically zero, particles swirl around vortices like fluid currents without collapsing into dead sinks.

Simulation Kinematics

Particle Trajectories & Line Segment Rendering

Instead of rendering thousands of disjoint dots, Somnia traces the continuous temporal history of each particle as a sequence of connected line segments.

Euler Integration & Boundary Behavior: 
// Step position
p.prevX = p.x;
p.prevY = p.y;
p.x += p.vx;
p.y += p.vy;

// Draw line segment
ctx.beginPath();
ctx.moveTo(p.prevX, p.prevY);
ctx.lineTo(p.x, p.y);
ctx.stroke();

Trail Decay & Screen Wrapping

  • Ethereal Decay Trails: On every animation tick, an ultra-faint semi-transparent rectangle of the background color (alpha 0.02 – 0.06) is blended over the canvas. Older lines slowly dissolve into atmospheric mist, mimicking fading dream memories.
  • Toroidal Wrapping & Discontinuity Guard: When a particle wraps across boundary edges, its prevX, prevY are immediately re-centered to avoid rendering long streaks across the entire canvas.

Architecture & Optimization

Rendering Optimization & Deterministic Reproduction

Achieving 60 frames per second with thousands of animated particles in HTML5 Canvas requires deliberate architectural constraints:

  • Fixed Pre-Allocated Particle Pool: Zero object allocations take place in the requestAnimationFrame loop. Particles are created once and recycled in-place, eliminating Garbage Collector (GC) micro-stutters.
  • High-DPI Retina Compensation: The canvas backing store is multiplied by window.devicePixelRatio, while CSS dimensions keep layout intact. This ensures razor-sharp lines on Retina displays without blurry upscaling.
  • Separation of Preview and Export: In the interactive studio, animation runs continuously at the display's variable refresh rate. For static high-res exports (2K/4K PNG), an offscreen canvas runs an exact sequence of 320 fixed-timestep ticks (dt = 1/60s), guaranteeing bit-for-bit reproducibility independent of when the user clicks.
  • Offline-First IndexedDB: Compositions are persisted as lightweight JSON configurations (seed, sleep data snapshot, parameters). No massive 10MB images need to be stored to restore an artwork.
